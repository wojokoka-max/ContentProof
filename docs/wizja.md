# Wizja produktu — ContentProof

ContentProof nie ma być kolejnym mechanicznym checkerem SEO.

Większość obecnych narzędzi:

* analizuje tylko długość zdań,
* liczbę słów kluczowych,
* procent nagłówków,
* lub generuje sztuczne rekomendacje.

ContentProof ma działać bardziej jak inteligentny redaktor jakości treści.

Projekt skupia się na:

* realnej czytelności,
* mobile UX,
* naturalności języka,
* strukturze logicznej,
* doświadczeniu użytkownika,
* oraz jakości komunikacji.

System ma rozumieć różnicę między:

* długim zdaniem,
* listą,
* sekcją UX,
* FAQ,
* instrukcją,
* blokiem składników,
* a normalnym akapitem narracyjnym.

ContentProof ma pomagać:

* twórcom,
* blogerom,
* freelancerom,
* małym firmom,
* copywriterom,
* oraz osobom publikującym treści bez dużej wiedzy SEO.

Najważniejsza idea:
nie tworzyć „bardziej poprawnych” tekstów.

Tworzyć teksty:

* bardziej ludzkie,
* bardziej czytelne,
* bardziej naturalne,
* i bardziej użyteczne.
