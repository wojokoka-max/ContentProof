# UX Readability — ContentProof

## Główna idea

Klasyczne readability tools analizują:

* długość zdań,
* sylaby,
* przecinki.

ContentProof analizuje:

* sposób czytania treści na ekranie,
* szczególnie na urządzeniach mobilnych.

---

# Mobile-first readability

System ma uwzględniać:

* długość bloków,
* skanowalność,
* oddech tekstu,
* rytm wizualny,
* długość sekcji,
* rozdzielenie treści.

---

# Bloki specjalne

System musi rozpoznawać:

* listy,
* FAQ,
* składniki,
* instrukcje,
* checklisty,
* sekcje UX,
* „W tym artykule znajdziesz”,
* „Najważniejsze”.

Nie wolno traktować ich jak zwykłych akapitów.

---

# Ściany tekstu

System powinien wykrywać:

* zbyt długie bloki,
* brak przerw,
* brak nagłówków,
* brak struktury wizualnej.

---

# Naturalny rytm

Dobra czytelność nie oznacza:

* przesadnie krótkich zdań,
* sztucznego uproszczenia,
* infantylizacji języka.

System ma wspierać:

* naturalny rytm,
* logiczne prowadzenie czytelnika,
* płynność czytania.

---

# Główna filozofia

Treść ma być:

* wygodna do czytania,
* lekka wizualnie,
* logiczna,
* i przyjazna użytkownikowi.

Nie „idealna pod algorytm”.
