# System ocen — ContentProof

## Główne założenia

ContentProof nie ocenia wyłącznie:

* długości zdań,
* liczby słów kluczowych,
* ani procentów.

System ma analizować:

* użyteczność,
* czytelność,
* naturalność,
* strukturę,
* UX,
* i jakość komunikacji.

---

# Typy ocen

## Błąd krytyczny

Problemy wpływające na:

* indeksację,
* UX,
* strukturę,
* brak kluczowych elementów SEO.

Przykłady:

* brak H1,
* brak title,
* brak meta description,
* brak canonical,
* brak struktury nagłówków.

---

## Ostrzeżenie

Problemy mogące pogorszyć:

* czytelność,
* SEO,
* UX.

Przykłady:

* ściana tekstu,
* bardzo długi akapit,
* przeciążenie słowami kluczowymi,
* powtarzalny rytm AI.

---

## Sugestia

Elementy opcjonalne poprawiające jakość.

Przykłady:

* dodatkowe linkowanie,
* rozbicie bloku,
* lepsze CTA,
* poprawa rytmu tekstu.

---

# UX Readability

System NIE może:

* karać list,
* karać składników,
* karać FAQ,
* karać krótkich sekcji UX.

System ma rozpoznawać:

* mobile scanning,
* bloki wizualne,
* oddech tekstu,
* rytm czytania.

---

# Human Layer

Analiza:

* sztucznej poprawności,
* pustych fraz,
* generyczności,
* przesadnego „AI tone”.

---

# Najważniejsza zasada

ContentProof ma pomagać pisać:

* bardziej naturalnie,
* bardziej czytelnie,
* bardziej ludzko,
* a nie bardziej „algorytmicznie”.
